# Propuesta comercial — Metales Infinity

Documento para presentar a Gael (dueño de Metales Infinity).

- **`Propuesta_Metales_Infinity_Aimarktech.docx`** — Documento final en Word (entregable).
- **`generar_propuesta.py`** — Generador del documento (fuente versionable).

## Regenerar el documento

```bash
python3 -m pip install python-docx
python3 generar_propuesta.py
```

El diseño usa la paleta y tipografías de la marca Aimarktech (azul `#0A74DA`, cian `#00C2FF`,
amarillo `#FFCE00`, tinta `#0e1b2c`; Montserrat / Lato).

## Notas

- Versión **corta y aterrizada**: sin promesas de ROI ni cifras infladas.
- Incluye las **dos opciones** (Catálogo + WhatsApp / Tienda completa) y las 5 preguntas
  pendientes para cerrar números con datos reales.
- Lo fiscal se menciona solo como referencia (opcional, a decisión de Gael).
- Datos de contacto tomados del material previo; **confirmar antes de enviar**.
